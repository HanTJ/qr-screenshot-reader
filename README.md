# QR 스크린샷 리더

QR 코드가 포함된 스크린샷이나 사진을 브라우저에서 분석하는 정적 웹앱입니다. QR 내용이 `http://` 또는 `https://` 웹주소이면 확인 가능한 링크와 **웹주소 열기** 버튼을 표시합니다.

## 기능

- 이미지 선택, 드래그 앤 드롭, 클립보드 붙여넣기
- QR 코드 위치 표시
- 웹주소 자동 분류 및 클릭 가능한 링크 제공
- 일반 텍스트 원문 표시와 복사
- 이미지 데이터를 외부 서버에 전송하지 않는 로컬 처리
- 모바일/데스크톱 반응형 UI

## 로컬 실행

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 테스트

```bash
npm test
npm run check
```
